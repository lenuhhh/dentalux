## 🚀 Запуск

```bash
npm install
npm run dev
```

Доступно за адресою: `http://localhost:5174` або `http://192.168.0.103:5174`

## 🗄️ Налаштування Supabase

### 1. Створіть проект на [supabase.com](https://supabase.com)

### 2. Отримайте ключі
- Перейдіть в **Settings → API**
- Скопіюйте `Project URL` та `anon public key`

### 3. Налаштуйте .env
```bash
cp .env.example .env.local
```

Заповніть файл:
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 4. Створіть таблиці
- Перейдіть в **SQL Editor** в Supabase
- Відкрийте файл `sql-migrations.sql`
- Скопіюйте весь код і запустіть

### 5. Тестуйте
- Перезавантажте додаток
- Спробуйте зареєструватися на `/register`
- Перейдіть у `/cabinet` щоб побачити персональні дані

## 🛡️ Безопасность

### RLS (Row Level Security)
Все таблицы защищены:
- Пользователи видят только **свои** данные
- Услуги и врачи доступны **всем**

### Обработка ошибок
- Все DB методы обернуты в try-catch
- Если Supabase недоступен, приложение работает в **mock режиме**
- Ошибки выводятся пользователю, не ломая страницы

## 📊 DB методы (src/supabaseClient.js)

```javascript
// Получить услуги
db.getServices()

// Получить врачей
db.getDoctors()

// Получить прием пользователя
db.getUserAppointments(userId)

// Создать прием
db.createAppointment({ user_id, appointment_date, ... })

// История лечения
db.getTreatmentHistory(userId)

// Профиль пользователя
db.getUserProfile(userId)

// Обновить профиль (UPSERT)
db.updateUserProfile(userId, profile)
```
